# MNIST-NEURAL-NETWORK
This project uses a Neural Network to recognize and classify handwritten digits (0–9) from the MNIST dataset. It involves image preprocessing, model training, and performance evaluation to achieve accurate handwritten digit recognition using Python and TensorFlow/Keras.

Project Overview

This project uses a Neural Network to recognize and classify handwritten digits (0–9) from the MNIST dataset. The model is trained using image data to identify handwritten numbers accurately.

Dataset

- MNIST Handwritten Digit Dataset
- 28 × 28 grayscale images
- 10 classes (digits 0–9)

Technologies Used

- Python
- TensorFlow / Keras
- NumPy
- Matplotlib

Project Workflow

1. Import required libraries.
2. Load the MNIST dataset.
3. Preprocess and normalize the images.
4. Build the Neural Network model.
5. Train the model using training data.
6. Evaluate model performance.
7. Predict handwritten digits.

Objective

To develop a Neural Network model that can accurately recognize handwritten digits using deep learning.

Conclusion

The project demonstrates how Neural Networks can be used for handwritten digit recognition and image classification.
